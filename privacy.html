Privacy Policy

Last updated: 28 September 2026

Openclaw is a private software application operated by a single individual for their own personal use. It is not a public service and has no users other than its owner.

What data is accessed

With the owner's explicit authorisation, the application accesses data belonging to the owner's own Google account — including Gmail messages, Google Calendar events, and Google Drive files — using Google's official OAuth 2.0 APIs.

How data is used

Accessed data is used solely to perform tasks the owner requests, such as searching the owner's own email, reading calendar entries, or retrieving files. Data is processed on the owner's own hardware.

How data is stored

OAuth credentials are stored locally on the owner's own hardware in an encrypted credential store. Message and file contents are not retained beyond the task at hand unless the owner chooses to save them locally.

Data sharing

No data is sold, rented, shared, or transmitted to any third party. The application does not use Google user data for advertising, analytics, or training machine learning models.

Data retention and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access immediately stops all further data access. Locally stored credentials can be deleted from the owner's hardware at any time.

Limited Use disclosure

Openclaw's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
